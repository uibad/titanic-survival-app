# 🚢 Titanic Survival Prediction

This project is a Machine Learning web application that predicts whether a Titanic passenger would survive based on passenger information.

## Features

* Predict Titanic passenger survival
* Interactive Streamlit user interface
* Trained Machine Learning model
* Simple and easy-to-use interface

## Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-learn
* Pickle

## Input Features

* Pclass
* Sex
* Age
* SibSp
* Parch
* Fare
* Embarked

## Project Structure

```
Titanic-Survival-Prediction/
│
├── app.py
├── titanic_model.pkl
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## Model

The model is trained on the Titanic dataset using Scikit-learn and predicts whether a passenger survived.
